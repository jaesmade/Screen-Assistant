Study Desk now includes a Windows x64 installer and a dedicated quick overlay.

## Install

Download `Study-Desk-0.2.0-Setup-x64.exe` and run the per-user setup. `SHA256SUMS.txt` contains its SHA-256 checksum. This release is unsigned; Windows may show an unknown-publisher warning.

## Included

- **Quick overlay:** press `Ctrl+Shift+Space` while Study Desk is running to show or hide a compact, draggable, always-on-top workspace. Capture and crop a question, extract text locally, and stream an explanation. `Esc` hides the overlay.
- **Tray controls:** closing the main window keeps the app available in the system tray. Open the desk or overlay from the tray; choose **Quit Study Desk** to exit.
- **Local OCR:** bundled English recognition works offline, with editable review, replace/append controls, and optional crop attachment.
- **Streaming explanations:** formatted Markdown and KaTeX math, with stop controls and visible partial responses after interruption.
- **Saved history:** searchable local questions, answers, and crops, with reopen/delete/clear controls.
- **Optimization:** lazy-loaded feature panels and answer formatting, minified renderer assets, a smaller OCR runtime, shared response handling, and more efficient history retention.
- **Dependency updates:** patched Electron/Vite and transitive dependencies; the release build passes `npm audit` with zero reported vulnerabilities.

## Notes

Add an OpenRouter API key in **Settings** for explanations. Requests use `openrouter/free`; availability and limits vary. OCR needs no API key. The API key is encrypted locally; saved question history is unencrypted local JSON. The app is intended for practice and assessments where AI assistance is allowed.

The overlay does not capture automatically. Global shortcut registration can fail if another application owns the shortcut; the tray menu and **Quick overlay** button remain available.

## Validation

TypeScript checks, regression tests, Electron integration tests, and the packaged-app smoke test cover native encryption, real offline OCR, streaming, history, and overlay security boundaries.

The Windows setup was also installed silently into a temporary folder, tested as an installed application, and uninstalled successfully.
